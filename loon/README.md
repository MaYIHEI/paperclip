# Loon 插件

Loon 专用插件文件,后缀 `.lpx`(Loon Plugin Extension,旧称 `.plugin`,内容格式相同)。

---

| 插件 | 功能 | 状态 | 使用链接 |
|---|---|---|---|
| [`paperclip-checkin/`](./paperclip-checkin/) | 签到合集:全部在用签到脚本的定时签到,签到开关默认全开,统一通知每天一条汇总;设置在 BoxJS | ✅ 维护中 | [点击复制](https://raw.githubusercontent.com/MaYIHEI/paperclip/refs/heads/main/loon/paperclip-checkin/paperclip-checkin.lpx) |
| [`paperclip-cookie/`](./paperclip-cookie/) | 集中抓取全部在用签到脚本的 Cookie(29 个),规则常开,抓完关掉插件;签到用签到合集 | ✅ 维护中 | [点击复制](https://raw.githubusercontent.com/MaYIHEI/paperclip/refs/heads/main/loon/paperclip-cookie/paperclip-cookie.lpx) |
| [`nodecheck/`](./nodecheck/) | 在节点/策略组页面检测代理出口、本机网络与远端 TCP 可达性，辅助判断节点阻断或离线 | ✅ 维护中 | [点击复制](https://raw.githubusercontent.com/MaYIHEI/paperclip/refs/heads/main/loon/nodecheck/nodecheck.lpx) |
